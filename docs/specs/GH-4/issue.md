## 背景・目的

メンテナンスの予定や新機能の案内を、利用者に知らせる手段がアプリの中に無い。今は運用担当者がメールを個別に送っていて、手間がかかるうえに見落とされる。

ログインした利用者がお知らせを一覧で見られるようにし、ダッシュボードにも新しいお知らせを表示する。お知らせは運用担当者がサーバーでコマンドを実行して登録する。

````text
## 背景

メンテナンスの予定や新機能の案内を、利用者に知らせる手段がアプリの中に無い。今は運用担当者がメールを個別に送っていて、手間がかかるうえに見落とされる。

## やりたいこと

- ログインした利用者が、お知らせの一覧を見られる画面（`/announcements`）を作る
- ダッシュボードにも、新しいお知らせを表示する
- お知らせは、運用担当者がサーバーでコマンドを実行して登録する

  ```sh
  php artisan announcement:create "<タイトル>" "<本文>"
  ```

## この issue でやらないこと

- 画面からのお知らせの登録、編集、削除（必要になったら別の issue にする）
- 既読・未読の管理、メールやプッシュでの通知
````
